# Jomidarpedia corrections

This repository collects corrections and photo offers for **Jomidarpedia (জমিদারপিডিয়া)**, a free bilingual guide to the zamindar houses, rajbaris and kacharis of Bangladesh.

It holds no code. Each report is a GitHub issue.

- **Something is wrong or missing on a site or trip page:** [report a correction](../../issues/new?template=correction.yml)
- **You have a photo you can share:** [offer a photo](../../issues/new?template=photo-offer.yml)

The "Suggest a correction" button on each page opens the form with the site ID, field and page address already filled in.

## Before you post

- **Issues are public.** Don't include phone numbers, home addresses or anything else private.
- **Please say how you know.** A book, an article, a sign at the site or your own visit (with the date) all help. Corrections are checked against sources before the site is updated.
- Family stories and local legends are welcome. They are kept apart from documented history on the site, and credited as oral accounts.
- English or Bangla is fine. ইংরেজি বা বাংলা, যেকোনো ভাষায় লিখতে পারেন।
